Program Time Tracker para Windows

Program Time Tracker es un programa para Windows, hecho con C++, Win32 api & Dear ImGui, diseñado para rastrear el uso de tus programas y visualizar datos de uso en distintos intervalos de tiempo (dia, semana, mes...).

Incluye un modo de AntiProcrastinacion que te permite establecer limites diarios para programas que te distraigan, con excepciones para los fin de semanas si asi es deseado. Para enforzar los limites diarios hay una opcion de recibir una notificacion tras posponer y Matar tras el primer posponer para enforzar los limites diarios.
Tambien incluye un parador automatico para rastrear tras un limite de minutos elegible de inactividad.

Hice este proyecto para probar mis habilidades despues del primer año de la carrera y para distraerme durante el verano, por ende el abuso de arrays dinamicas manuales en vez de usar smart vectors, aunque eventualmente decidi usarlos para el aspecto de visualizacion de datos para evitar volverme loco.
